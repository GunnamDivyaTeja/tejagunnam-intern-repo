# Learning Goals

## What do I hope to learn from this internship?

I want to learn how machine learning is used in a real product that real people use every day, not just in uni assignments. At uni, the dataset is usually clean and the goal is a good accuracy score. At Focus Bear, I want to see how an ML feature like AI website blocking is actually built, tested and improved, and how decisions are made when user privacy and user experience matter just as much as accuracy.

I also want to learn how a real software team works, like using GitHub issues, pull requests, code reviews, stand-ups and sprint planning.

## What skills am I most excited to develop?

- Building and improving ML features that are part of a live app
- Working with LLM APIs like OpenAI, including writing good prompts and checking the outputs
- Evaluating models properly, like looking at false positives and false negatives and not only accuracy
- Working with user data in a privacy-safe way (anonymising data, using only what is needed)
- Writing clean code that other people can review and maintain

## What do I think I can contribute to the team?

- My ML and Python knowledge from uni, to help with AI features like website blocking and motivational messages
- Testing the AI features and finding cases where they get it wrong
- Using the app every day and giving honest feedback on what is confusing or annoying
- Being careful and checking things before I commit. For example, during onboarding I found that the setup README had the wrong format for the `.env` file, and I noticed several help centre articles that look out of date.

## What is one area I feel less confident in that I would like to improve?

I am less confident about deploying ML models into production, for example on AWS, and keeping them working well after they go live. Most of my experience so far is with training models in notebooks. I would like to understand how a model gets from a notebook into an app, and how to monitor it once real users are using it.

## What does success in this internship look like for me?

- I finish the onboarding within the expected time
- I contribute to at least one real ML feature that gets merged and is used by users
- I attend the stand-ups and meetings and give regular updates
- I get better at working in a team and asking for help at the right time
- I finish with a High Distinction and leave good handover notes for the next intern
